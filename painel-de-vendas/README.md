# Projeto Painel de Vendas

Projeto desenvolvido em **Microsoft Excel** com o objetivo de acompanhar o desempenho comercial por meio de um dashboard interativo, permitindo analisar indicadores de vendas, desempenho de vendedores e evolução dos resultados ao longo do tempo.

O projeto demonstra a utilização de recursos do Excel para organização de dados, construção de indicadores (KPIs), elaboração de gráficos e desenvolvimento de dashboards voltados à análise comercial e apoio à tomada de decisão.

---

# Tecnologias

- Microsoft Excel
- Fórmulas Avançadas
- Tabelas
- Gráficos
- Dashboard
- KPIs

---

# Objetivo

Desenvolver uma solução em Excel para monitorar o desempenho das vendas, permitindo identificar tendências, comparar resultados entre vendedores e acompanhar indicadores comerciais por meio de visualizações intuitivas.
