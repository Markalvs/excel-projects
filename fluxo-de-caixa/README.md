# Projeto Fluxo de Caixa

Projeto desenvolvido em **Microsoft Excel** com o objetivo de controlar e analisar o fluxo de caixa de uma empresa por meio de um dashboard interativo, permitindo acompanhar receitas, despesas, saldos e indicadores financeiros de forma clara e objetiva.

O projeto demonstra a utilização de recursos do Excel para organização de dados, construção de indicadores (KPIs), elaboração de gráficos e desenvolvimento de dashboards voltados ao controle financeiro e apoio à tomada de decisão.

---

# Tecnologias

- Microsoft Excel
- Fórmulas Avançadas
- Tabelas
- Gráficos
- Dashboard
- KPIs

---

# Objetivo

Desenvolver uma solução em Excel para monitorar o fluxo de caixa, permitindo acompanhar a evolução financeira, identificar os principais impactos nas receitas e despesas e fornecer informações para apoiar a tomada de decisão.
