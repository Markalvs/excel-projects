# Projeto Ativos

Projeto desenvolvido em **Microsoft Excel** com o objetivo de controlar e analisar uma carteira de ativos por meio de um dashboard interativo, permitindo acompanhar indicadores patrimoniais e a evolução dos investimentos de forma simples e visual.

O projeto demonstra a utilização de recursos do Excel para organização de dados, construção de indicadores (KPIs), criação de gráficos e desenvolvimento de dashboards voltados ao acompanhamento financeiro.

---

# Tecnologias

- Microsoft Excel
- Fórmulas Avançadas
- Tabelas
- Gráficos
- Dashboard
- KPIs

---

# Objetivo

Desenvolver uma solução em Excel para acompanhar a evolução dos investimentos, permitindo visualizar rapidamente o patrimônio total, a distribuição dos ativos e os principais indicadores financeiros.
