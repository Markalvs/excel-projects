# Projeto Perfil do Cliente

Projeto desenvolvido em **Microsoft Excel** com o objetivo de analisar o perfil dos clientes por meio de um dashboard interativo, permitindo visualizar indicadores relacionados ao comportamento de compra, perfil demográfico e padrões de consumo.

O projeto demonstra a utilização de recursos do Excel para organização de dados, construção de indicadores (KPIs), elaboração de gráficos e desenvolvimento de dashboards voltados à análise de clientes e apoio à tomada de decisão.

---

# Tecnologias

- Microsoft Excel
- Fórmulas Avançadas
- Tabelas
- Gráficos
- Dashboard
- KPIs

---

# Objetivo

Desenvolver uma solução em Excel para analisar o perfil dos clientes, permitindo identificar padrões de comportamento, acompanhar indicadores comerciais e fornecer informações para apoiar estratégias de marketing, relacionamento e tomada de decisão.
